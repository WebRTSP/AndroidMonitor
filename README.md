# Video Monitor

Android application to preview video stream from IP Cams.

## Features
* ONVIF and RTSP protocol support
* Automatic discovery of ONVIF IP Cams on the local network
* Screen wake-up on motion detection (for ONVIF IP Cams)
* Remote video stream access

## Tech Stack
* Kotlin
* Jetpack Compose
* Jetpack Navigation 3
* Hilt DI
* C++
* gSOAP
* GStreamer
* WebRTSP
